## Возможности

- **Установка в один клик** любой официальной версии Blender: докачка при обрыве, проверка по официальным SHA-256, параллельная распаковка.
- **Три канала** прямо с серверов Blender:
  - **Стабильные** — все релизы с download.blender.org, LTS отмечены.
  - **Ежедневные** — alpha, beta и release candidate с builder.blender.org.
  - **Экспериментальные** — сборки открытых pull request'ов со ссылкой на PR.
- **Библиотека** — запуск любой установленной версии, версия по умолчанию, избранное, свои названия и аргументы запуска для каждой сборки, добавление уже установленного Blender.
- **Обновление на месте** — у ежедневных и экспериментальных сборок появляется кнопка «Обновить», старая сборка заменяется, настройки переносятся.
- **Недавние файлы** из истории всех версий Blender с превью, встроенными в `.blend`. Файл открывается в той версии, в которой был сохранён.
- **Перетаскивание** `.blend` в окно — выбор версии Blender для открытия.
- **Уведомления** о новых релизах, новых ежедневных версиях и обновлениях установленных сборок — системные и во встроенном центре уведомлений.
- **Новости** с blender.org и блога разработчиков Blender.
- **Трей** с быстрым запуском, автозапуск, сворачивание в трей.
- **Нативный вид** — полупрозрачное окно (Mica в Windows 11, vibrancy в macOS), светлая и тёмная темы, интерфейс на русском и английском.

## Где хранятся сборки

По умолчанию в Windows — `%USERPROFILE%\BlendStack` (папку можно сменить в настройках, сборки перенесутся). Структура `stable` / `daily` / `experimental` совпадает с Blender Launcher, поэтому его библиотеку можно открыть напрямую.

## Сборка из исходников

Нужны [Rust](https://rustup.rs) 1.85+, [Node.js](https://nodejs.org) 20+ и [зависимости Tauri](https://v2.tauri.app/start/prerequisites/) для вашей ОС.

```bash
npm install
npm run app:dev      # запуск с горячей перезагрузкой
npm run app:build    # установщики в src-tauri/target/release/bundle
```
